# Statistics & Feature Analysis Practice

- `statistics_basics.ipynb`: Essential statistical concepts for Machine Learning (mean, median, mode, variance, standard deviation, IQR, skewness, kurtosis, Z-score outlier detection, hypothesis testing / T-test).
- `statistical_feature_analysis_project.ipynb`: Statistical feature analysis on `house_features.csv` (descriptive statistics, skewness/kurtosis, Z-score and IQR outlier detection, Pearson correlation and p-values, T-test hypothesis testing, Z-score vs Min-Max scaling, and visualizations).
- `../csv/statistical_features_summary.csv`: Generated statistical feature summary output file.
