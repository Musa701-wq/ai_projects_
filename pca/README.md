# Principal Component Analysis (PCA) Practice

- `pca_basics.ipynb`: Core PCA steps from scratch using NumPy (mean centering, covariance matrix, eigenvalues and eigenvectors, explained variance ratio, and 1D projection).
- `pca_project.ipynb`: Customer feature dimensionality reduction project on `customer_pca_data.csv` (feature standardization, explained variance scree plot, 5D to 2D reduction using Scikit-learn `PCA`, feature loadings, and 2D cluster visualization).
- `../csv/pca_projection.csv`: Generated 2D principal components output file from the project.
