# NumPy Practice

- `numpy_basics.ipynb`: Basic and essential NumPy functions (arrays, slicing, reshape, stack, statistics, conditions, sorting, dot product).
- `vector_basics.ipynb`: Basic vector operations (creation, addition/subtraction, scaling, norm/magnitude, unit vector, dot product, cosine similarity, distance, projection).
- `matrix_basics.ipynb`: Matrix operations (special matrices, transpose, determinant, inverse, trace, rank, eigenvalues/eigenvectors, solving Ax=b, SVD).
- `players_project.ipynb`: Simple cricket players stats analysis project (runs, average, strike rate, fifties, CSV export, Matplotlib/Seaborn charts).
- `vector_project.ipynb`: Simple movie recommendation system using vectors (feature vectors, magnitude, cosine similarity, Euclidean distance, CSV export, charts).
- `../csv/players_summary.csv`: Generated output file from the players project.
- `../csv/movie_recommendations.csv`: Generated output file from the vector project.
