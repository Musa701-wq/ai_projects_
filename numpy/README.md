# NumPy Practice

- `numpy_basics.ipynb`: NumPy ke basic aur zaroori functions (arrays, slicing, reshape, stack, stats, conditions, sorting, dot product).
- `vector_basics.ipynb`: Vectors ke basic aur zaroori operations (creation, addition/subtraction, scaling, norm/magnitude, unit vector, dot product, cosine similarity, distance, projection).
- `matrix_basics.ipynb`: Matrices ke specific aur advanced operations (special matrices, transpose, determinant, inverse, trace, rank, eigenvalues/vectors, solving Ax=b, SVD).
- `players_project.ipynb`: 5 cricket players ke stats ka simple project (runs, average, strike rate, fifties, summary export, Matplotlib/Seaborn charts).
- `vector_project.ipynb`: Movie recommendation system ka simple project using vectors (feature vectors, vector magnitude, cosine similarity, distance, summary export, recommendation charts).
- `../csv/players_summary.csv`: Players project ka generated output file.
- `../csv/movie_recommendations.csv`: Vector project ka generated output file.
