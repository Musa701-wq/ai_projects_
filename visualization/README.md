# Data Visualization Practice

- `visualization_basics.ipynb`: Essential plots using Matplotlib and Seaborn (line plots, multi-line plots, bar charts, histogram/KDE distributions, scatter plots with hue/size, boxplots for outliers, correlation heatmaps).
- `sales_visualization_project.ipynb`: E-commerce sales visualization project on `sales_data.csv` (monthly revenue/profit trends, category and regional bar charts, histogram/KDE, boxplots, scatter plots, and correlation heatmap).
- `../csv/sales_category_summary.csv`: Generated category summary output file from the project.
