# Calculus for Machine Learning Practice

- `calculus_basics.ipynb`: Machine Learning ke liye basic calculus ke zaroori concepts (functions & curves, limits, derivatives, differentiation rules, tangent lines, partial derivatives, gradient vector, chain rule, SymPy symbolic math, second derivatives).
- `gradient_descent_project.ipynb`: Gradient Descent optimization algorithm from scratch (loss function, gradient update rule, convergence path on cost curve, learning rate comparisons, history export).
- `../csv/gradient_descent_history.csv`: Project ka generated step-by-step optimization history file.
