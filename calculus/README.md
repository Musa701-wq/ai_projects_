# Calculus for Machine Learning Practice

- `calculus_basics.ipynb`: Core calculus concepts for Machine Learning (functions & curves, limits, derivatives, differentiation rules, tangent lines, partial derivatives, gradient vectors, chain rule, SymPy symbolic math, second derivatives).
- `gradient_descent_project.ipynb`: Gradient Descent optimization algorithm from scratch (loss function, gradient update rule, convergence path on cost curve, learning rate comparisons, history export).
- `../csv/gradient_descent_history.csv`: Generated step-by-step optimization history file.
